## ✅ Что работает по-настоящему (без симуляции)

Модуль `osint_real.py` — реальное ядро. Эти функции выполняют настоящие
запросы, а при отсутствии данных честно сообщают об этом (НЕ выдумывают):

**Бесплатно, без ключей:**
- 🔎 Проверка username на 10 платформах — `username_checker.py` (реальный HTTP)
- 🌐 DNS-записи (A/AAAA/MX/NS/TXT/CNAME) и reverse DNS
- 📄 WHOIS домена
- 📍 Геолокация IP (ip-api.com → ipwho.is → ipinfo.io)
- 🔐 TLS/SSL-сертификат хоста
- 📧 Валидация email: формат + реальная проверка MX-записей
- 🌍 HTTP-заголовки и определение технологий
- 🔓 Криптоанализ: брутфорс Цезаря, частотный анализ, декодеры — `steganography_crypto.py`
- 🫥 Текстовая стеганография (zero-width Unicode)

**Требуют ваш API-ключ** (задаётся в `config.py` или переменной окружения):
- 💥 Проверка утечек HaveIBeenPwned → `HIBP_API_KEY`
- 🛰️ Данные хоста Shodan → `SHODAN_API_KEY`

**Демонстрация формата (помечены как `[ДЕМО]`):** разбор VK-профиля
(нужен официальный VK API + токен), генератор учебных фишинг-шаблонов
(офлайн, письма НЕ отправляются).

### Веб-версия

```bash
python webapp.py        # http://127.0.0.1:5000
```
Вкладки: Username · Цезарь · Декодер · Стеганография · Домен (DNS+WHOIS) ·
IP (гео+rDNS) · Email (формат+MX, + HIBP при наличии ключа).

### Быстрая проверка из консоли

```bash
python osint_real.py dns_records github.com
python osint_real.py email_validate user@gmail.com
python username_checker.py torvalds
```
